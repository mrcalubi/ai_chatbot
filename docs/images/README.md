# Screenshot Placeholders

This directory should contain screenshots referenced in the main README.md:

- `ui-home.png` - Screenshot of the chatbot home page (upload area visible)
- `upload.png` - Screenshot showing the drag-and-drop upload interface
- `answer-citation.png` - Screenshot of an answer with citations visible

## How to Add Screenshots

1. Take screenshots of the chatbot UI
2. Save them with the filenames above
3. Update README.md if filenames differ
4. Ensure images are optimized (PNG or JPG, reasonable file size)

## Recommended Screenshots

### ui-home.png
- Show the full chatbot interface
- Include upload area, file list, and question input box
- Keep it clean and professional

### upload.png
